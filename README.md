## 📋 Descripción del Proyecto

Este proyecto es una **web interactiva y profesional** que presenta un caso práctico completo de optimización del customer journey para CARGLASS utilizando HubSpot y herramientas de automatización con Inteligencia Artificial.

A diferencia de un PDF tradicional, esta propuesta es una **interfaz web moderna, responsive y profesional** que demuestra tanto el expertise en estrategia digital como habilidades técnicas de desarrollo web.

## 🎯 Contenido Incluido

### 1. **Lifecycle del Cliente** (7 etapas)
- Awareness → Consideration → Reserva → Periodo de Espera → Reparación → Post-Venta → Loyalty

### 2. **Automatizaciones Prioritarias**
- **Automatización 1:** Recuperar "Carrito Abandonado" (Timeline 0h-24h)
- **Automatización 2:** Evitar No-show (Timeline 48h-6h)

### 3. **Configuración CRM HubSpot**
- Estructura de Contactos, Deals, Segmentaciones
- Workflows automáticos y Reporting

### 4. **Herramientas IA Propuestas**
- Chatbot WhatsApp (Twilio + OpenAI)
- Agente de Voz IA
- Recomendación Dinámica VAPS

### 5. **Estrategia de Implementación**
- 3 Iniciativas Prioritarias Q1
- A/B Test Analysis
- Aspectos operacionales

## 🚀 Cómo Usar

### Opción 1: Localmente
```bash
git clone https://github.com/pablogarciaverdu1-max/clinica_garcia_reboll.git
cd clinica_garcia_reboll
python3 -m http.server 8000
# Abre http://localhost:8000
```

### Opción 2: GitHub Pages
1. Ve a Settings → Pages
2. Selecciona "Deploy from a branch"
3. Elige `claude/vigilant-tesla-hwywca` → `/root`
4. ¡Listo! Web pública automáticamente
